# Room Resonance Finder — code

This repository holds only the application code for Room Resonance Finder.

Project documentation, discovery notes, hypothesis register, and the
authoritative progress log live in a separate location (a personal life
vault, not published here):

```
projects/programming/audio-tools/room-resonance-finder/
  PROJECT_STATE.md   — current snapshot (goal, phase, confirmed facts, hypotheses)
  PROJECT_LOG.md      — append-only history of sessions and experiments
  claude-project-bridge.md / claude-project-brief.md — instructions for coding agents
  product-notes.md, technical-notes.md, dsp-notes.md, ux-notes.md,
  test-protocol.md, risks.md, references.md
```

Before making any non-trivial change here, read `PROJECT_STATE.md` and the
last entries of `PROJECT_LOG.md` in that location, and update them after a
substantive session. This repository does not keep its own task list or
progress log — those live only in the vault.
